# User Management Guide

This guide explains how to manage user accounts and preferences in ImpactX.

## Overview

The user management system provides tools for:

- User profile customization
- Preference management
- Privacy controls
- Account security

## Profile Management

Users can manage their profiles through the profile page:

- Update personal information
- View donation history
- Track achievements
- See impact contributions

## Settings

The settings page allows users to customize their experience:

### Appearance
- Theme selection (light/dark/system)
- Dark mode toggle

### Notifications
- Email notification preferences
- Push notification preferences
- Notification frequency settings

### Privacy
- Analytics consent
- Data sharing preferences
- Data management tools

### Account
- Profile information updates
- Password management
- Two-factor authentication
- Connected accounts

## User Roles

ImpactX supports different user roles:

- **Donors**: Can make donations and track impact
- **NGO Representatives**: Can manage projects and upload verification data
- **Admins**: Can manage the entire platform

## Security Features

- Password encryption
- Two-factor authentication
- Session management
- Account recovery

## Data Privacy

We are committed to protecting user privacy:

- All personal data is encrypted
- Users control their data sharing preferences
- GDPR compliant data handling
- Regular security audits

## API Endpoints

For programmatic access to user management features:

```
GET /api/users/profile
PUT /api/users/profile
GET /api/users/preferences
PUT /api/users/preferences
POST /api/users/change-password
```

## Troubleshooting

Common issues and solutions:

- Forgotten password recovery
- Two-factor authentication setup
- Account verification
- Connected account management
