# Impact Stories Guide

This guide explains how to view and share impact stories in ImpactX.

## Overview

Impact stories showcase real transformations from communities we serve. These stories:

- Highlight individual and community transformations
- Demonstrate the real-world impact of donations
- Provide transparency and accountability
- Inspire continued support

## Story Structure

Each impact story includes:

- Compelling title
- Detailed narrative
- Beneficiary information
- Location details
- Date of impact
- Visual elements (photos, videos)
- Connection to specific projects
- Measurable outcomes

## Browsing Stories

The impact stories page provides several ways to find stories:

### Search
Users can search stories by:
- Title
- Description
- Location
- Beneficiary name

### Filters
Stories can be filtered by:
- Category (Education, Health, Food Security, etc.)
- Location (Country/Region)
- Date range

### Sorting
Stories can be sorted by:
- Date (newest/oldest)
- Impact size
- Category
- Location

## Reading Stories

Each story page includes:

- Engaging narrative
- High-quality images
- Beneficiary quotes
- Project connection
- Impact metrics
- Call to action

## Sharing Stories

Users can share stories through:

- Social media platforms
- Email
- Direct links
- Embedded widgets

## Story Creation (Admin)

Administrators can create new stories:

- Write compelling narratives
- Upload media assets
- Connect to projects
- Add impact metrics
- Set publication date
- Tag with categories

## Media Management

Story media includes:

- High-resolution photos
- Video testimonials
- Infographics
- Before/after comparisons

## Verification

Stories are verified through:

- NGO confirmation
- Beneficiary consent
- Photo authenticity
- Data accuracy

## API Integration

For developers, stories can be accessed via API:

```
GET /api/stories
GET /api/stories/{id}
POST /api/stories
PUT /api/stories/{id}
DELETE /api/stories/{id}
```

## Best Practices

When creating impact stories:

- Focus on the beneficiary
- Use authentic quotes
- Include measurable outcomes
- Respect privacy
- Maintain accuracy
- Ensure cultural sensitivity
- Use high-quality media
- Connect to specific projects

## Community Engagement

Stories can drive engagement through:

- Comment sections
- Sharing incentives
- Story contests
- User-generated content
- Volunteer testimonials
- Donor spotlights

## Reporting

Story performance metrics include:

- View counts
- Share statistics
- Engagement rates
- Donation correlations
- User feedback
