# Projects Guide

This guide explains how to browse, filter, and interact with projects in ImpactX.

## Overview

The projects system allows users to:

- Browse active humanitarian projects
- Filter projects by category, location, and status
- View project details and progress
- Make donations to projects

## Project Structure

Each project includes:

- Title and description
- Location information
- Funding goal and progress
- End date
- Category classification
- Impact metrics

## Browsing Projects

The projects page provides several ways to find projects:

### Search
Users can search projects by:
- Title
- Description
- Location

### Filters
Projects can be filtered by:
- Category (Education, Health, Food Security, etc.)
- Location (Country/Region)
- Status (Active, Completed, etc.)

### Sorting
Projects can be sorted by:
- Progress percentage
- Funding goal
- End date
- Number of donors

## Project Details

Each project page includes:

- Detailed description
- Progress tracking
- Donor information
- Impact stories
- Verification status
- Related projects

## Donation Process

To donate to a project:

1. Select a project from the projects list
2. Click the "Donate" button
3. Enter donation amount
4. Connect wallet
5. Confirm transaction
6. Receive confirmation

## Impact Tracking

Projects track impact through:

- Beneficiary count
- Progress milestones
- Verification status
- Completion reports

## API Integration

For developers, projects can be accessed via API:

```
GET /api/projects
GET /api/projects/{id}
POST /api/projects/{id}/donate
GET /api/projects/{id}/impact
```

## Project Creation (Admin)

Administrators can create new projects:

- Set funding goals
- Define project duration
- Assign categories
- Add location data
- Upload images
- Set impact metrics

## Verification

Projects are verified through:

- NGO reports
- IoT sensor data
- Drone imagery
- Satellite data
- Community feedback

## Reporting

Project reporting includes:

- Progress updates
- Financial transparency
- Impact assessments
- Completion certificates
